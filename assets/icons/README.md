# Кастомные иконки маркеров

Эта папка предназначена для опциональных кастомных иконок маркеров карты
(например, PNG/SVG-файлы для каждого типа контроля).

По умолчанию приложение использует иконки Font Awesome, отрисованные
через `L.divIcon` в `js/map.js`, поэтому файлы в этой папке не обязательны.

Если вы хотите подключить свои иконки:
1. Поместите файлы сюда (например, `icon-vik.png`, `icon-uzk.png` и т.д.)
2. В `js/map.js` замените функцию `buildIcon()` на использование `L.icon({ iconUrl: 'assets/icons/icon-vik.png', ... })`
