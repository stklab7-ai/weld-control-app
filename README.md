# Weld Control — подача заявок на сварочный контроль

Веб-приложение для подачи и учёта заявок на сварочный контроль (Вик, Узк, Рк, Цд) с интерактивной картой.

## Запуск приложения

### Способ 1 (рекомендуемый) — через батник
1. Дважды кликните на `start.bat`
2. Откройте браузер и перейдите по адресу: http://localhost:8080

### Способ 2 — вручную
- Если установлен Python: `python -m http.server 8080`
- Если установлен Node.js: `npx http-server -p 8080`
- Или просто откройте `index.html` в браузере

## Технологии
- HTML + CSS + JavaScript (Vanilla, ES6+)
- Leaflet.js — карта (через CDN)
- Font Awesome — иконки (через CDN)
- localStorage — хранение данных, без бэкенда

## Как пользоваться
1. При первом запуске введите своё имя — оно будет указано автором всех создаваемых заявок.
2. Кликните по карте, чтобы выбрать точку контроля — справа откроется форма новой заявки.
3. Заполните название объекта, тип контроля и остальные поля, нажмите «Создать заявку».
4. Заявка появится маркером на карте и карточкой в списке слева.
5. Чтобы отредактировать заявку — кликните по карточке в списке, по маркеру на карте (двойной клик) или нажмите «Редактировать» в попапе маркера.
6. Чтобы переместить точку заявки — перетащите её маркер на карте.
7. Чтобы удалить заявку — нажмите иконку корзины на карточке и подтвердите удаление.
8. Все заявки можно выгрузить в JSON-файл кнопкой «Экспорт JSON».

## Данные
Все заявки хранятся локально в браузере (localStorage), без передачи на сервер. При очистке данных браузера или использовании другого браузера/устройства список заявок будет пустым.
